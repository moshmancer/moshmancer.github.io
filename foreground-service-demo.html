Moshmancer Foreground Service Demo

This short, sanitized recording demonstrates the user-visible foreground-service flow used for FOREGROUND_SERVICE_DATA_SYNC.

  1. The user starts an SSH terminal session to the demo host.
  2. The user runs a command in the terminal.
  3. The user leaves Moshmancer and returns to the home screen.
  4. Moshmancer's ongoing notification remains visible with the active connection status.
  5. Tapping the notification returns the user to the still-connected terminal session.
